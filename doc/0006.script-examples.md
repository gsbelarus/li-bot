## Взаимодействие с профилем

1. IMPORTANT! If a CAPTCHA or verification screen appears,
   stop the script immediately and set the script result
   and the VPS status to "ALERT".
2. Make sure the current tab is a LinkedIn tab.
3. Go to the LinkedIn My Network page.
4. Wait for the page to finish loading.
5. Stay on the page for 8-10 seconds using a random value. 
   Move the mouse around naturally during the wait.
6. Find the section called "Popular on LinkedIn", 
   "People you may know ...".
7. In that section, open the first profile card that looks 
   like a person or creator profile.
8. Wait for the profile page to finish loading.
9. Check the logs to see if any scripts have been run for this profile in the last 30 days. If so, skip this profile and choose the next one.
10. Stay on the page for 10-12 seconds using a random value. 
   Move the mouse around naturally during the wait.
11. On the LinkedIn profile, scroll the page slightly if needed, 
   then look for a way to open the full posts or activity list. 
   First look for a visible control labeled "Show all activity", 
   "See all activity", "See all posts", or "Show all posts". 
   If that is not present, look for a section or tab titled "All activity", 
   "Activity", or "All Posts" and open it.
12. If there is no way to open the full posts or activity list, end the script.
13. Open the full posts list.
14. Wait for the posts page to finish loading.
15. Stay on the page for 10-12 seconds using a random value. 
    Move the mouse around naturally during the wait.
16. Find the first post in the list that is less than 6 months old and has not been processed before. If there are no posts less than 6 months old, end the script.
17. Bring the post into view exactly.
18. Move focus to that same post.
19. On that same post, find the More button.
20. If there is no More button on that same post, end the script.
21. If needed, scroll slightly until the More button on that same 
    post is visible.
22. Click the More button on that same post.
23. Wait briefly for the More menu to appear.
24. Stay on the page for 10-15 seconds using a random value.
25. Click Like on that same post, if it is not liked yet.
26. If the post is less than 14 days old, also write a relevant comment. 
    The comment should be relevant to the content of the post. For example, if the post shares an achievement, you can write a congratulatory comment. If the post shares a problem, you can write a comment with advice or support. 
27. Add a log entry that the post was processed, including the post URL and the timestamp.
28. Go back to the profile page.    

1. Открыть ленту новостей контакта. УРЛ для открытия ленты новостей: https://www.linkedin.com/in/{contactPublicIdentifier}/recent-activity/all/. Где {contactPublicIdentifier} - это публичный идентификатор контакта, который можно получить из его профиля. Например, если профиль контакта имеет URL https://www.linkedin.com/in/john-doe-123456789/, то его публичный идентификатор будет john-doe-123456789.
2. Прочитать пост который сделан (или репостнут) текущим контактом. Развернуть и прочитать его полностью и понять содержимое, просмотреть посты от 20-80 секунд.  В случае с несколькими фотографиями - промотреть все, в случае с пдф файлом - пролистать его полностью. 
3. Затем поставить реакцию (лайк) на пост. 
4. Написать короткий комментарий, который будет релевантен данному посту. 
5. Повторить для 3-5 публикаций. 

## Активность с новыми контактами

1. перейти на страницу My Network 
2. перейти на страницу Connections 
3. Открыть последний добавленный контакт
4. Открыть ленту его постов 
5. Проанализировать последнюю публикацию, которая была сделана. Прочитать полностью текст поста, просмотреть все фотографии к нему, обратить внимание на дату публикации. 
6. Если пост был опубликован больше 2 недель назад, то поставить реакцию (лайк), если меньше 2 недель – то поставить реакцию (лайк) и написать комментарий. Реакция и комментарий должны быть релевантны содержанию поста. Например, если в посте человек делится достижением, то можно поставить лайк и написать комментарий с поздравлением. Если в посте человек делится проблемой, то можно поставить лайк и написать комментарий с советом или поддержкой. Не нужно рассматривать посты, на которые
нами же были написаны комментарии ранее, поставлена реакция (лайк) или которые уже были обработаны.
7. Вернуться обратно к списку контактов и повторить те же действия еще с 4 новыми контактами (если они есть). 
8. если у контакта постов нет или последний пост старше 6 месяцев — пропустить контакт, зафиксировать в логе с пометкой «inactive», перейти к следующему.
