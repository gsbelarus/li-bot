1. The task is to create a Remote Controller system, which is a NodeJS Express server running on remote VPS. This server will manage Chrome instances and communicate with the Open Claw Bot. The Remote Controller will allow operators to control and monitor their VPS and Chrome instances remotely through a web interface, saving time and increasing efficiency by eliminating the need for manual logins and interactions with the VPS.
2. The source code for the Remote Controller is located in the `rc` folder of the repository. Init the project there using `pnpm`. Put the source code for the Remote Controller in the `src` folder inside `rc`. The entry point of the server should be `src/index.ts`.
3. The Remote Controller should use authentication via shared secret key. The secret key should be stored in an environment variable `REMOTE_CONTROLLER_SECRET_KEY`. The Remote Controller should validate the secret key for every incoming request and reject requests with an invalid or missing secret key with a 401 Unauthorized response.
4. Check that the secret key is stored per VPS, so each VPS can have its own secret key. This allows for better security and flexibility in managing multiple VPS. For that check the `Control Center Server` code. If there is no support for storing the secret key per VPS, implement it in the `Control Center Server` and update the database schema accordingly. Then update the docs in the doc\0002.remote-vps-registry.md to reflect the changes made to the `Control Center Server` for storing the secret key per VPS.
